# Интерфейс AGENT.Dashboard

Next.js 16 (App Router) + React 19 + Tailwind 4. Архитектура — Feature-Sliced Design.

## Команды

| Команда | Что делает |
| --- | --- |
| `yarn dev` | дев-сервер на 3000, `/api/*` проксируется на бэкенд (`FLEET_API`, по умолчанию 127.0.0.1:8770) |
| `yarn build` | продакшен-сборка с проверкой типов |
| `yarn generateApi` | перегенерация типов из `/openapi.json` бэкенда (бэкенд должен быть запущен) |
| `yarn lint` | ESLint |
| `yarn lint:fsd` | границы слоёв FSD (steiger) |
| `yarn format` | Prettier |

## Слои

`app` → `widgets` → `shared`. Слой `pages` не заводится: его роль играют маршруты App Router
в `src/app` — они тонкие и только собирают виджеты.

- `src/app` — маршрут, оболочка, тема, шрифты, сборка вкладок.
- `src/widgets` — самостоятельные блоки: обзор, лента вызовов, разбор вызова, редактор агентов,
  запуск задач, контекст пространства, лимиты провайдеров, расход Claude Code.
- `src/shared` — типизированный клиент API (`api`), общие компоненты (`ui`), состояние (`model`),
  утилиты (`lib`), палитра серий (`config`).

## Типы

Руками типы ответов не пишутся. Схемы живут в `dashboard/schemas.py` на бэкенде,
`yarn generateApi` кладёт сгенерированное в `src/shared/api/schema.ts`, а `types.ts` даёт им
человеческие имена.

## Палитра графиков

`src/shared/config/palette.ts` — фиксированный порядок цветов серий. Он проверен валидатором
палитр на тёмной поверхности: полоса светлоты OKLCH 0.48–0.67, контраст ≥3:1, различимость
при дальтонизме ΔE ≥ 10 для соседних пар. Порядок менять нельзя — распадётся проверенное соседство.
