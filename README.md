# AGENT.Dashboard

Свой отдел разработки из дешёвых моделей: Claude Code как главный архитектор, GLM и DeepSeek
(и любые другие, каких заведёте) — как команда. Управляется из Claude Code через MCP,
наблюдается через локальный дашборд с полной статистикой расходов.

```
Вы (технический директор)
      │
Claude Code — главный архитектор: файлы, git, финальное ревью, решения
      │  MCP-сервер fleet (stdio, локально)
      ├── consultant   второе мнение по архитектуре
      ├── opponent     оппонент в совете (намеренно другая семья моделей)
      ├── senior       сложная логика, рефакторинг, интеграции
      ├── junior ×N    простой код и рутина, параллельно
      ├── vision       скриншоты, макеты, схемы → текст
      ├── analyst      логи, метрики, JSON, аномалии
      └── condenser    сжатие страниц, материалов и правил
      │
память флота data/context/<проект>/  +  журнал data/logs/events.jsonl → дашборд
```

**Топология — звезда, а не общий чат.** Свободная переписка агентов жжёт токены и уплывает
от задачи. Обсуждение идёт внутри процесса (`fleet_council`), наружу отдаются позиции сторон —
решение принимает главный архитектор.

**Агенты не пишут в файлы.** Они возвращают код текстом, применяет его Claude после проверки:
так каждое изменение проходит ревью и видно в диффе.

## Раскладка

| Каталог | Что там | Подробности |
| --- | --- | --- |
| `backend/` | MCP-сервер флота, API на FastAPI, промпты ролей | [backend/README.md](backend/README.md) |
| `frontend/` | интерфейс на Next.js: статистика, агенты, контекст | [frontend/README.md](frontend/README.md) |
| `data/` | память флота: контекст проектов, состав команды, ключи | приватный репозиторий |

Правила для агентов: общие — [`CLAUDE.md`](CLAUDE.md), частные — в `backend/CLAUDE.md`
и `frontend/CLAUDE.md`.

## Запуск

Первый раз:

```bash
git clone https://github.com/AlexandraG-code/AGENT.Dashboard.git
cd AGENT.Dashboard
git clone https://github.com/<логин>/AGENT.Dashboard.DATA.git data   # своя приватная память

python3 -m venv backend/.venv && backend/.venv/bin/pip install -r backend/requirements.txt
cd frontend && yarn install && cd ..
```

Дальше два терминала:

```bash
# терминал 1 — API и вызовы моделей
cd backend && ./run-dashboard.sh          # http://localhost:8770

# терминал 2 — интерфейс
cd frontend && yarn dev                   # http://localhost:3000
```

Интерфейс живёт на 3000 и сам проксирует `/api` на 8770 — в браузере нужен только 3000.
По адресу 8770 лежит Swagger (`/docs`) и ReDoc (`/redoc`): посмотреть эндпоинты и подёргать
их руками.

Ключи провайдеров задаются в интерфейсе на вкладке «Модели» (лягут в `data/secrets.json`)
либо берутся из окружения — `GLM_API_KEY`, `DEEPSEEK_API_KEY`.

Инструменты `fleet_*` внутри Claude Code:

```bash
claude mcp add fleet -s user -- /путь/к/AGENT.Dashboard/backend/run-mcp.sh
```

## Экономика

GLM — подписка Coding Plan: маржинальная стоимость вызова **ноль**, ограничение только по
параллелизму. DeepSeek — оплата по токенам. Отсюда главное правило: **всё, что GLM делает
приемлемо, идёт в GLM; деньги DeepSeek покупают только то, чего GLM не может.**

| Модель | Вход / 1M | Кэш-хит | Выход / 1M |
| --- | --- | --- | --- |
| `glm-5.3`, `glm-5.3-flash`, `glm-4.6v` | 0 | 0 | 0 |
| `deepseek-v4-flash` | $0.14 | $0.0028 | $0.28 |
| `deepseek-v4-pro` | $0.435 | $0.003625 | $0.87 |

Типовая задача (8k вход, 10k выход): senior ≈ $0.012, оппонент ≈ $0.004, джун — бесплатно.

Три приёма экономии заложены в код:

1. **Префиксный кэш.** У DeepSeek попадание в кэш в 50 раз дешевле промаха, поэтому неизменный
   блок контекста проекта (`_core.md` и `_rules.md`) всегда идёт первым и побайтово одинаково.
2. **Размышления по делу.** Размышления биллятся как выход, поэтому у джунов думанье выключено,
   а у senior и оппонента включено — там оно и есть предмет покупки.
3. **Объёмное — в файлы.** Длинные ответы уходят в `data/out/`, в контекст Claude — выжимка и путь.

## Память и приватность

Контекст проектов, состав команды и ключи лежат в `data/` — этот каталог целиком в `.gitignore`.
Инструмент публичный, контекст рабочих проектов — нет, поэтому память удобно держать отдельным
приватным репозиторием, склонированным в `data/`.

В промпт каждого агента целиком уходят две заметки пространства: `_core.md` (описание и цели)
и `_rules.md` (правила и соглашения). Правила можно не переписывать руками — дашборд соберёт
их из репозитория проекта (`CLAUDE.md`, `AGENTS.md`, `.claude/rules/*.md`, `.cursorrules`,
включая вложенные `backend/` и `frontend/`) и сожмёт бесплатным condenser.

## Почему не NotebookLM

У NotebookLM нет публичного API — программно брать оттуда контекст нельзя. Контекст-банк
закрывает ту же задачу: markdown-заметки с поиском по словам, без внешних зависимостей и индекса.
