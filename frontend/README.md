# Интерфейс AGENT.Dashboard

Next.js 16 (App Router) + React 19 + Tailwind 4 + TypeScript strict. Архитектура —
Feature-Sliced Design, границы слоёв проверяет steiger.

## Запуск

```bash
yarn install
yarn dev            # http://localhost:3000
```

`/api/*` проксируется на бэкенд (по умолчанию `http://127.0.0.1:8770`, переопределяется
переменной `FLEET_API`), поэтому порт бэкенда нигде во фронте не зашит и CORS не нужен.

| Команда | Что делает |
| --- | --- |
| `yarn dev` | дев-сервер на 3000 |
| `yarn build` | продакшен-сборка с проверкой типов |
| `yarn generateApi` | типы из `/openapi.json` бэкенда (бэкенд должен быть запущен) |
| `yarn lint` | ESLint |
| `yarn lint:fsd` | границы слоёв FSD (steiger) |
| `yarn format` | Prettier |

## Разделы

- **Обзор** — расход по дням, разрезы по моделям и проектам (вход и выход токенов раздельно),
  таблица «проект × модель», остатки провайдеров и объём работы самого Claude Code.
  Переключатель «Все проекты / один» пересчитывает страницу целиком. Кнопка «Выгрузить отчёт
  в PDF» печатает светлый макет без интерфейсных элементов — файл сохраняет сам браузер.
- **Лента** — живая хроника вызовов; клик по вызову открывает панель с полным входом
  (системный промпт, контекст, задача), размышлениями и ответом модели.
- **Запуск** — задача одному агенту или совет.
- **Агенты** — состав команды и промпты; отдельной карточкой показан Claude Code.
- **Модели** — реестр провайдеров и моделей, ключи и проверка подключения.
- **Пространства** — проект заводится здесь: идентификатор, название, описание и цели,
  правила и соглашения (можно собрать из репозитория проекта).
- **Контекст** — наполнение памяти: файл или вставленный кусок текста разбирается в черновик
  заметки, дальше её читает человек и сохраняет.

Кнопка **«Вид»** в шапке — настройки читаемости: кегль, шрифт, насыщенность, контраст и фон.
Сохраняются в браузере и применяются до первой отрисовки.

## Слои

`app` → `widgets` → `shared`. Слоя `pages` нет: его роль играют маршруты App Router в `src/app` —
они тонкие и только собирают виджеты.

- `src/app` — маршрут, оболочка, тема, шрифты, сборка вкладок.
- `src/widgets` — самостоятельные блоки: обзор, лента, разбор вызова, агенты, модели,
  пространства, контекст, лимиты провайдеров, расход Claude Code, настройки вида.
- `src/shared` — клиент API (`api`), общие компоненты (`ui`), состояние (`model`),
  утилиты (`lib`), палитра серий (`config`).

Виджеты не импортируют друг друга: общий блок собирается в `app`, общие данные берутся хуком
из `shared/model`.

## Типы

Руками типы ответов не пишутся. Схемы живут в `backend/dashboard/schemas.py`,
`yarn generateApi` кладёт сгенерированное в `src/shared/api/schema.ts`, а `types.ts` даёт им
человеческие имена.

## Палитра графиков

`src/shared/config/palette.ts` — фиксированный порядок цветов серий, проверенный валидатором
палитр на тёмной поверхности: полоса светлоты OKLCH 0.48–0.67, контраст ≥3:1, различимость
при дальтонизме ΔE ≥ 10 для соседних пар. Порядок менять нельзя — распадётся проверенное соседство.
