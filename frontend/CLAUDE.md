# Интерфейс флота

Next.js 16 (App Router) + React 19 + Tailwind 4 + TypeScript strict. Архитектура —
Feature-Sliced Design, границы проверяет steiger.

## Команды

| Команда | Что делает |
| --- | --- |
| `yarn dev` | http://localhost:3000, `/api/*` проксируется на бэкенд (`FLEET_API`) |
| `yarn build` | сборка с проверкой типов |
| `yarn generateApi` | типы из `/openapi.json` бэкенда (бэкенд должен быть запущен) |
| `yarn lint` / `yarn lint:fsd` / `yarn format` | ESLint, границы FSD, Prettier |

Перед коммитом должны быть зелёными все три: `yarn lint`, `yarn lint:fsd`, `yarn build`.

## Слои

`app` → `widgets` → `shared`. Слоя `pages` нет: его роль играют маршруты App Router
в `src/app` — они тонкие и только собирают виджеты.

- **Виджеты не импортируют друг друга.** Нужен общий блок — композиция поднимается в `app`,
  а общие данные берутся хуком из `shared/model`.
- Наружу слайс отдаёт только то, что перечислено в его `index.ts`.

## Правила

- **Типы ответов API не пишутся руками.** `src/shared/api/schema.ts` генерируется;
  человеческие имена ему даёт `types.ts`. Новое поле — сначала в схему бэкенда.
- Компоненты функциональные, без `React.FC`, пропсы — `interface`, `...props` спредом.
- **Prettier:** табы (ширина 4), без `;`, одинарные кавычки, printWidth 120.
- Никаких `any` и `@ts-ignore`; необязательные поля обрабатываются явно (`??`).
- **setState синхронно в теле `useEffect` запрещён** (правило `react-hooks/set-state-in-effect`):
  состояние либо инициализируется из пропсов, либо сбрасывается через `key` на компоненте.
- **Доступность не опция:** видимый focus-visible, `label` связан с полем через `htmlFor`,
  кликабельное — это `button` с `cursor-pointer`, контраст текста не ниже 4.5:1.
  Размеры текста задаются классами в rem: пиксельные размеры не масштабируются настройкой
  кегля в панели «Вид», а она нужна людям со слабым зрением.
- **Палитра серий на графиках** — `src/shared/config/palette.ts`, порядок фиксирован и
  проверен валидатором (контраст, дальтонизм, полоса светлоты). Порядок не менять.
