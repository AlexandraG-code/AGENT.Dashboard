# AGENT.Dashboard

Свой «отдел разработки» из дешёвых моделей под управлением Claude Code: MCP-сервер флота,
API и веб-интерфейс со статистикой расходов.

> Язык проекта — русский. Комментарии, сообщения коммитов и тексты интерфейса — по-русски.

## Раскладка

| Каталог | Что там |
| --- | --- |
| `backend/` | MCP-сервер флота, FastAPI, промпты ролей. Свои правила — `backend/CLAUDE.md` |
| `frontend/` | интерфейс на Next.js. Свои правила — `frontend/CLAUDE.md` |
| `data/` | память флота: контекст проектов и состав команды. Отдельный приватный репозиторий |

Правила ниже общие для обеих частей; частности — в `CLAUDE.md` соответствующей папки.

## Общие правила

- **Никакого подавления ошибок:** ни `# type: ignore`, ни `@ts-ignore`, ни `any`, ни
  `eslint-disable`. Чинится причина, а не симптом.
- **Комментарий объясняет «почему», а не «что».** Строчка `# увеличиваем счётчик` — мусор;
  строчка про то, что префикс промпта обязан быть побайтово одинаковым ради кэша, — нет.
- **Не выдумывать данные.** Если провайдер не отдаёт остаток лимита, в интерфейсе так и
  написано, а не подставлено правдоподобное число. То же про цены и статистику.
- **Ключи и контекст рабочих проектов в git не уезжают.** Ключи — `data/secrets.json`,
  контекст — приватный репозиторий `data/`. Публичный репозиторий содержит только инструмент.
- **Схема данных живёт в одном месте.** Ответы API описаны в `backend/dashboard/schemas.py`;
  из них строятся и Swagger на `/docs`, и типы фронта. Руками типы ответов не пишутся.
- **Документация — блоком над сущностью, а не построчно.** У компонента — JSDoc с `@param`
  на каждое свойство; у модуля и неочевидной функции — docstring. Построчные комментарии
  внутри интерфейсов и датаклассов не пишем.
- **Файл — про одну вещь.** Свалка из десятка функций над основным содержимым разносится
  по сегментам (`model/`, `lib/` во фронте; отдельный модуль в бэкенде), даже если функции мелкие.
- **Не писать руками то, что есть в библиотеке.** Во фронте это antd 5: кнопки, поля, таблицы,
  вкладки, модалки берутся оттуда. Стили — только SCSS-модули, инлайн-стилей нет.
- Коммиты — с префиксом в квадратных скобках: `[feat]`, `[fix]`, `[refactor]`, `[docs]`.

## Что нужно знать про флот

- Роли (`consultant`, `opponent`, `senior`, `junior`, `vision`, `analyst`, `condenser`)
  задаются в дашборде и хранятся в `data/team.json`; в коде — только значения по умолчанию.
- Промпты ролей — `backend/roles/*.md`, перечитываются по mtime без перезапуска сервера.
- Агенты не пишут в файлы и не ходят в интернет мимо своих инструментов: они возвращают
  текст, а применяет его главный (Claude Code или человек).
- Обсуждение агентов между собой идёт внутри процесса (`council`), наружу отдаются позиции
  и разногласия. Свободный чат агентов жжёт токены и уплывает от задачи.
